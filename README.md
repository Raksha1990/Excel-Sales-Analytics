# Excel Sales & Finance Analytics

## 📌 Project Overview

This project focuses on analyzing sales and financial data using Microsoft Excel. The aim is to understand customer performance, evaluate sales against targets, and track the company's financial performance across different markets and time periods.

I worked on preparing and transforming the data, building a data model, and creating DAX calculations to develop five reports covering Sales and Financial Analytics.

The project is divided into two main areas: Sales Analysis and Financial Analysis.

## 🎯 Project Objectives

### 1. Sales Analysis

The objective of the sales analysis is to understand customer contributions, evaluate market performance, and identify areas where sales performance can be improved.

## ⚙️ Data Preparation & Modelling

Before developing the reports, I worked on preparing the data and creating a structured data model.

The main activities included:

- Following the ETL (Extract, Transform, Load) process.
- Extracting and transforming data using Power Query.
- Creating a Date Table to support time-based analysis.
- Deriving fiscal months and quarters.
- Establishing relationships between tables using Power Pivot.
- Integrating additional data into the existing data model.
- Creating calculated columns and DAX measures for analysis.

## 📊 Key Areas of Analysis
